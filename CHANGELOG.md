# Changelog

Здесь фиксируются заметные изменения продукта и документации. История технических изменений остаётся в Git.

## Unreleased

### Added
- Опорная структура документации DP_Clock.
- Видение продукта, архитектурный обзор и дорожная карта.
- Принципы local-first для расписаний и необязательного ИИ.
- Версия 0.0.0: приложение на Kotlin, Jetpack Compose и Material 3 с одним экраном — текущее время в круге (D-004).
- Сборка через Gradle wrapper, установка Android SDK, отладочные APK в ветке `debug-builds` (D-005), учёт зависимостей — `docs/PROVENANCE.md`.
- Состав MVP и первое устройство приёмки — D-006; состав публичной версии 1.0 — D-007.

### Changed
- Проект определён как самостоятельная реализация с нуля.
- Исследование AOSP DeskClock больше не является обязательным стартовым этапом.
- Roadmap и TODO переведены на последовательность «спецификация → каркас → ядро времени → расширения».

### Notes
- Код приложения — только версия 0.0.0: один экран с текущим временем.
- Код стороннего DeskClock не копировался. Неудачная попытка workflow импорта не добавила в репозиторий upstream-файлов; workflow удалён.
