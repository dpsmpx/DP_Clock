# Changelog

Здесь фиксируются заметные изменения продукта и документации. История каждого технического изменения остаётся в Git.

## Unreleased

### Added
- Начальная опорная структура документации DP_Clock.
- Видение продукта и исходная концепция часов.
- Roadmap от исследования до подготовки к выпуску.
- Принципы local-first для расписаний и необязательного ИИ.
- Документы о процессе разработки, качестве, безопасности и интеграции с Android.
- Правила заимствования и учёт происхождения — docs/PROVENANCE.md.
- Версия 0.0.0: приложение на Kotlin, Jetpack Compose и Material 3 с одним экраном — текущее время в круге (D-004).
- Сборка через Gradle wrapper, установка Android SDK и отладочные APK в ветке `debug-builds` (D-005).

### Changed
- DP_Clock — собственное приложение; из AOSP DeskClock — только отдельные файлы по Apache 2.0 с записью происхождения (D-003).

- Принцип «Сначала исследование, затем реализация» снят: код и исследование идут параллельно (D-004).

### Removed
- Workflow импорта всего AOSP DeskClock в `/reference` и документ о снимке.

### Notes
- Этот bootstrap-коммит документальный: исходный код приложения, сборка и тесты не добавлялись.
