# D-001 — Документация как исходная опора

- **Статус:** Accepted
- **Дата:** 2026-10-19
- **Область:** организация проекта

## Контекст

Репозиторий начинается с одного README. До реализации кода необходимо разделить видение продукта, технические гипотезы, активные задачи и подтверждённые решения, не смешивая планы с результатами.

## Решение

Использовать следующую структуру источников истины:

- README.md — краткая точка входа и состояние проекта.
- TODO.md — только незавершённые задачи ближайшего горизонта.
- ROADMAP/ROADMAP.md — этапы, цели и критерии завершения.
- DECISIONS/ — значимые решения и их история.
- CHANGELOG.md — заметные изменения.
- docs/ — продуктовые, архитектурные, технические, исследовательские и тестовые документы.

## Последствия

- При существенном изменении направления обновляются документы.
- Статус сборки, кода и тестов подтверждается фактическими результатами.
- История выполненных задач хранится в changelog и Git, а не в бесконечно растущем TODO.
