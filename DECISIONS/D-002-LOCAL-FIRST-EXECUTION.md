# D-002 — Локальное исполнение времени и необязательный ИИ

- **Статус:** Accepted as a design principle; ИИ (пп. 2, 3, 5) отменён [D-026](D-026-SCOPE-CUTS.md) 31 октября 2026, local-first (пп. 1, 4) остаётся
- **Дата:** 2026-10-19
- **Область:** надёжность и архитектура

## Контекст

Будильники и таймеры чувствительны ко времени. API нейросети или сетевой сервис могут быть недоступны, медленны или платны.

## Решение

Будущая архитектура должна придерживаться принципа local-first для исполнения времени:

1. Созданные расписания исполняются приложением и Android, не требуя обращения к сети при каждом срабатывании.
2. ИИ может предлагать структурированные операции над моделью времени через ограниченный набор инструментов.
3. Приложение самостоятельно валидирует результат, показывает существенные изменения и при необходимости запрашивает подтверждение.
4. Недоступность ИИ не мешает созданию, редактированию, срабатыванию и отключению обычных будильников.
5. ИИ не получает произвольного доступа к shell, файлам, секретам или не связанным с задачей системным операциям.

## Последствия

Модель времени и правила валидации принадлежат приложению, а не провайдеру ИИ. Реальные механизмы Android и ограничения точных будильников предстоит исследовать; решение не утверждает, что интеграция уже реализована.
