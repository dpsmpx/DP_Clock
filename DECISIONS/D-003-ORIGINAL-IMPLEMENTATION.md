# D-003 — Собственная реализация DP_Clock с нуля

- **Статус:** Accepted
- **Дата:** 2026-10-19
- **Область:** источник кода, архитектура и план разработки

## Контекст
Изначально рассматривался вариант скопировать исходный код AOSP DeskClock в каталог reference. От этого отказались до получения копии исходников.

## Решение
1. Разрабатывать DP_Clock с нуля в собственном репозитории.
2. Не копировать в проект исходный код DeskClock или других сторонних приложений.
3. Использовать существующие приложения как функциональные ориентиры: сравнивать публично видимые возможности, сценарии и UX, формируя собственные решения.
4. Использовать официальную документацию Android и публичные Android APIs для изучения платформенных контрактов.
5. Любую будущую стороннюю зависимость или ассет проверять отдельно на происхождение, лицензию и необходимость.
6. Язык, package ID, minSdk/targetSdk и окончательный MVP определить отдельными решениями после уточнения требований.

## Последствия
- Roadmap начинается с требований, изучения платформы и выбора стека, а не с клонирования upstream-кода.
- Архитектура и модель данных DP_Clock принадлежат проекту.
- Документы описывают целевое поведение, а не копируемую структуру чужого приложения.

## Пересмотр
Решение можно изменить только отдельной записью при конкретной обоснованной необходимости использовать внешнюю библиотеку/код и после проверки лицензии и совместимости.
