# D-034 — Google Tasks убран: только свои задачи — версия 0.21.0

- **Статус:** Accepted — слово автора 31 октября 2026; на телефоне ещё не проверено (З9 в [плане](../docs/QUALITY/DEVICE_TEST_PLAN.md))
- **Дата:** 2026-10-31
- **Область:** задачи; заменяет [D-032](D-032-OWN-TASKS.md), п. 6 (Google Tasks через браузер), и остаток [D-031](D-031-TASKS.md) о внешних сервисах; [D-028](D-028-SYNC-AND-TASKS-DIRECTION.md), п. 2, больше не действует.

## Контекст

В 0.18.0 убраны Todoist и TickTick, в 0.19.0 вход Google переделан на браузер. Автор вход в браузере не пробовал. 31 октября 2026 он сказал: «Google Tasks тоже убери, оставь только задачи внутри приложения».

## Решение

1. **Таск-менеджеров нет.** Задачи — только свои: срок, напоминание, повтор, заметка, «В календарь», постоянные, подзадачи, история отметок (D-032, D-033).
2. **Из приложения убраны:**
   - раздел Google Tasks в настройках, окно входа и страница возврата в браузере;
   - задачи Google в «Часах», в «Задачах», в уведомлении после будильника и в виджете;
   - разбор ответов Google и вход с PKCE в ядре;
   - инструкция по Google Cloud.
3. **Старые ключи стираются.** При первом запуске 0.21.0 после разблокировки удаляются файл ключей (`tasks-keys.bin`: Todoist и TickTick из 0.18.0, клиент и ключ обновления Google из 0.19.0–0.20.0) и его ключ Android Keystore. Файл `tasks.json` переписывается без задач Google — остаётся выбор показа. Доступ, выданный Google раньше, можно отозвать в аккаунте Google («Безопасность» → «Сторонние приложения»).
4. **Сеть.** Задачам сеть не нужна. Разрешение на интернет остаётся только ради погоды (D-019); `ACCESS_NETWORK_STATE` — ради синхронизации (D-030).

## Аргументы

- Слово автора.
- Без внешних сервисов задачи работают без сети и аккаунтов, а ключей на телефоне нет.

## Последствия

- План проверки: пункт З6 (Google Tasks) снят; добавлен З9 — обновление с 0.20.0.
- Схема базы не меняется: свои задачи и отметки (схема 18) остаются как были.

## Пересмотр

- Понадобится обмен задачами с другим приложением — новым решением: какой сервис, какие данные уходят.
