# Журнал решений

В этой папке фиксируются решения, которые влияют на архитектуру, безопасность, продуктовый формат или стоимость дальнейших изменений.

## Правила

- Каждое решение получает постоянный ID и отдельный файл.
- Статусы: **Proposed**, **Accepted**, **Superseded**, **Rejected**.
- В решении указываются контекст, варианты, аргументы, последствия и условия пересмотра.
- Принятое решение синхронизируется с README, roadmap и соответствующими документами.
- Предложение не означает, что функция реализована.
