# DP_Clock

**DP_Clock** — самостоятельное Android-приложение часов, разрабатываемое с нуля. AOSP DeskClock и другие часы можно изучать как функциональные ориентиры, но исходный код чужих приложений не копируется в проект.

> **Статус:** версия 0.0.0 — один экран с цифровыми часами в круге ([D-004](DECISIONS/D-004-STACK-AND-VERSION-0.0.0.md)). Остальное в документах — планы и открытые решения, а не реализованные функции.

## Основная идея
Создать гибкий, умный и удобный центр управления временем: будильники, мировые часы, таймеры, секундомер, гибкие расписания, составные таймерные сценарии и необязательный ИИ-помощник для настройки обычным языком.

## Принципы
1. **Собственная реализация.** Не копировать исходники AOSP DeskClock или других приложений.
2. **Надёжность прежде интеллектуальности.** Уже созданные будильники и таймеры не зависят от сети или API нейросети.
3. **Простые действия остаются простыми.** Расширенные возможности не перегружают основной экран.
4. **Единая модель данных.** Настройки, созданные человеком или ИИ, проходят одинаковую валидацию.
5. **Факты отдельно от планов.** Реализованные, протестированные, запланированные и гипотетические возможности обозначаются явно.
