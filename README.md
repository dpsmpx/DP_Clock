# DP_Clock

**DP_Clock** — проект по исследованию и развитию гибкого, умного и удобного приложения часов для Android. В качестве исходной точки рассматривается AOSP DeskClock, известный как пакет com.android.deskclock.

> **Статус:** документальный bootstrap. На момент этого коммита в репозитории нет реализации приложения. Документы описывают видение, планы и открытые решения, а не уже реализованные функции.

## Основная идея

Развить классические часы Android в надёжный центр управления временем: будильники, мировые часы, таймеры, секундомер, гибкие расписания, составные таймерные сценарии и необязательный слой ИИ для создания настроек на естественном языке.

## Принципы

1. **Надёжность прежде интеллектуальности.** Будильники и таймеры должны работать без интернета и API нейросети.
2. **Простые действия остаются простыми.** Расширенные возможности не должны перегружать основной экран.
3. **Одна модель данных.** Настройки, созданные человеком или ИИ, проходят одинаковую проверку.
4. **Разделять факт и план.** Реализованные, протестированные, запланированные и гипотетические функции документируются раздельно.
5. **Сначала исследование, затем реализация.** До написания кода следует определить продуктовый формат, техническую основу, ограничения Android и лицензионные условия.

## Текущее состояние

- Создана базовая структура опорной документации.
- Исходная концепция продукта записана.
- Не решено, будет ли результат самостоятельным APK, форком AOSP или частью собственной ROM.
- Исследование конкретной версии DeskClock, её лицензии, сборки и ограничений Android — открытая задача.
- Код приложения, сборка и тесты в этом коммите не добавляются.
