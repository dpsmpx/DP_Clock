# Google Tasks: проект Google Cloud для DP_Clock

- **Статус:** нужно один раз автору ([D-031](../../DECISIONS/D-031-TASKS.md), п. 4). Без этого «Подключить Google Tasks» показывает шаги ниже.
- **Почему:** Google пускает приложение к Google Tasks только через OAuth-клиент для Android в проекте Google Cloud. Клиент знает пакет приложения и отпечаток ключа подписи. Секрета у Android-клиента нет, в коде DP_Clock ничего не хранится: Google Play services узнаёт приложение по пакету и подписи.

## Шаги

Все шаги — на [console.cloud.google.com](https://console.cloud.google.com) под аккаунтом, в котором ваши задачи.

1. **Проект.** Вверху — выбор проекта → «Новый проект», например «DP Clock».
2. **API.** «API и сервисы» → «Библиотека» → найти «Google Tasks API» → «Включить».
3. **Окно запроса доступа** (OAuth consent screen, раздел «Google Auth Platform»).
   - Тип — «Внешний».
   - Название — «DP Clock», почта поддержки — ваша.
   - Доступ (scope) добавлять не обязательно: приложение просит `https://www.googleapis.com/auth/tasks` само.
   - Режим:
     - **«Тестирование»** — добавьте свой аккаунт в тестовые пользователи. Google просит войти заново раз в 7 дней.
     - **«В работе»** (кнопка «Опубликовать приложение») — проверка Google не нужна для себя. При входе Google покажет «Приложение не проверено» → «Дополнительно» → «Перейти». Вход бессрочный.
4. **Клиент.** «Учётные данные» → «Создать учётные данные» → «Идентификатор клиента OAuth» → тип «Android»:
   - **название пакета** — `com.dpsmpx.dpclock`;
   - **отпечаток SHA-1** — `21:4D:70:12:D4:3B:6C:70:DF:74:78:AC:97:35:A0:D8:48:E3:F5:51`.

     Это отладочный ключ `app/debug.keystore`, им подписаны все сборки из `debug-builds` (D-005). Проверить: `keytool -list -v -keystore app/debug.keystore -storepass android -alias androiddebugkey`.
5. **Телефон.** DP Clock → Настройки → «Задачи» → Google Tasks → окно Google → выбрать аккаунт → «Разрешить».

## Если не получилось

- **Снова «Google ещё не знает DP Clock»** — пакет или SHA-1 введены с ошибкой. Ещё бывает, что Google не успел: изменения в консоли доходят за несколько минут.
- **«Доступ заблокирован»** — аккаунта нет в тестовых пользователях, а приложение в режиме «Тестирование».
- **Нет окна Google** — на телефоне нет Google Play services или они выключены.
