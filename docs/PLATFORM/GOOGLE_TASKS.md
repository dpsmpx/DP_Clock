# Google Tasks: проект Google Cloud для DP_Clock

- **Статус:** нужно один раз автору ([D-032](../../DECISIONS/D-032-OWN-TASKS.md), п. 6). Свои задачи DP Clock работают и без этого.
- **Почему:** Google пускает приложение к Google Tasks только через клиент OAuth в проекте Google Cloud. Вход в браузере Google оставил клиенту типа «Приложение для ПК»: браузер после входа возвращает ответ на `http://127.0.0.1:<порт>` телефона, там его ждёт DP Clock. Идентификатор и секрет клиента вводятся в приложении. В коде и репозитории их нет, на телефоне они хранятся зашифрованными.

## Шаги

Все шаги — на [console.cloud.google.com](https://console.cloud.google.com) под аккаунтом, в котором ваши задачи. Проект и Google Tasks API из 0.18.0 (D-031) годятся; Android-клиент больше не нужен.

1. **Проект.** Вверху — выбор проекта → «Новый проект», например «DP Clock».
2. **API.** «API и сервисы» → «Библиотека» → «Google Tasks API» → «Включить».
3. **Окно запроса доступа** (OAuth consent screen, раздел «Google Auth Platform»).
   - Тип — «Внешний»; название — «DP Clock»; почта поддержки — ваша.
   - Режим:
     - **«Тестирование»** — в «Аудитория» → «Тестовые пользователи» добавьте свой аккаунт. Google просит войти заново раз в 7 дней.
     - **«В работе»** (кнопка «Опубликовать приложение») — проверка Google для себя не нужна. При входе Google покажет «Приложение не проверено» → «Дополнительно» → «Перейти». Вход бессрочный.
4. **Клиент.** «Клиенты» (или «Учётные данные») → «Создать клиент» → тип **«Приложение для ПК»** (Desktop app) → название любое → «Создать». Скопируйте **идентификатор клиента** и **секрет клиента**.
5. **Телефон.** DP Clock → Настройки → «Задачи» → Google Tasks → вставить идентификатор и секрет → «Войти в браузере».
   - Откроется браузер: выберите аккаунт, разрешите доступ к Google Tasks.
   - Страница «Готово — Google Tasks подключён» → «Вернуться в DP Clock».

## Если не получилось

Внизу экрана — ответ Google:

| Ответ Google | Что поправить |
|---|---|
| `invalid_client` | Идентификатор или секрет введены с ошибкой, либо тип клиента — не «Приложение для ПК». |
| `access_denied` | Аккаунта нет в тестовых пользователях, или доступ не разрешили. |
| `redirect_uri_mismatch` | Клиент не «Приложение для ПК»: у веб-клиента возврат на 127.0.0.1 не разрешён. |
| `timeout` | Браузер не вернулся за 5 минут — начните снова. |
| `HTTP 403` при обновлении | Google Tasks API не включён в проекте (шаг 2). |
