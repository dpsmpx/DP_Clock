# План проверки срабатывания на устройстве

- **Статус:** план; выполняется, когда в сборке появятся соответствующие функции. Будильники — первыми (D-006).
- **Устройство:** Redmi Note 13, Android 15, HyperOS 2.0.213 (D-006); дальше — по матрице устройств перед выпуском.
- **Основа:** [исследование платформы](../RESEARCH/ANDROID_PLATFORM.md), [D-008](../../DECISIONS/D-008-PLATFORM-MECHANISMS.md). Каждая проверка подтверждает или опровергает «предположения» исследования.

## Как записывать результат

Для каждого прогона: сборка (`debug-<коммит>.apk`), устройство и версия HyperOS, настройки приложения (автозапуск, экономия батареи, закрепление в «Недавних», разрешения), шаги, ожидаемое и фактическое время сигнала, отклонение в секундах. Результаты — в этот документ, таблицей под проверкой, с датой.

Общие условия, если не сказано иное: приложение установлено из `debug-builds`, все разрешения выданы, телефон не на зарядке, экран выключен, приложение не на экране.

## Как вызвать состояния без ожидания

Если телефон подключён к компьютеру по ADB:

- Doze: `adb shell dumpsys deviceidle force-idle`, выход — `adb shell dumpsys deviceidle unforce`;
- ожидание приложения: `adb shell am set-inactive com.dpsmpx.dpclock true`;
- загрузка без перезагрузки: `adb shell am broadcast -a android.intent.action.BOOT_COMPLETED com.dpsmpx.dpclock`.

Без компьютера — реальные условия: ночь с неподвижным телефоном (Doze), настоящая перезагрузка.
