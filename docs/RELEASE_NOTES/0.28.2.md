Сборка выпуска теперь подписана ключом разработчика (секреты KEYSTORE_* в GitHub Actions).

Предыдущая 0.28.1 и более ранние публичные APK были с общим отладочным ключом из репозитория. Эта версия — первая с твоей подписью: её можно ставить поверх отладочных сборок только после удаления предыдущей (разные подписи).

## Изменения относительно 0.28.1

- Подпись APK выпуска — ключ разработчика через секреты CI (D-039 / обязательная подпись).
- Версия и versionCode подняты, чтобы появился новый GitHub Release с новыми файлами.

Функциональность приложения та же, что в 0.28.1 (восход/закат, будильники по солнцу, ключевые будильники, самопроверка «Прозвонит ли будильник», копия по расписанию и т.д.).

## Установка

Скачайте `dp-clock-0.28.2.apk` на телефон. Если раньше стояла сборка с debug.keystore — сначала удалите старое приложение (данные при удалении пропадут, если не сделали копию).

Исходный код — в этом репозитории; как собрать самому — `docs/DEVELOPMENT/BUILD.md`.
