Проверка обновлений из GitHub Releases: раз в сутки (и по кнопке) приложение узнаёт о новой версии, показывает скрываемый баннер и скачивает APK выпуска внутри себя; установку делает система.

## Новое

- **Проверка обновлений** — «О приложении»: переключатель (по умолчанию включён), «Проверить сейчас».
- **Баннер** на главном экране: «Обновить» / «Скрыть», смахивание в сторону, сам исчезает через 30 секунд; раскладку интерфейса не меняет.
- **Скачивание APK** во внутренний кэш и запуск установщика Android (нужно разрешение «установка неизвестных приложений» для DP Clock).
- Запрос к api.github.com без сведений о пользователе; выбирается asset `dp-clock-*.apk` (не debug).

## Установка

Скачайте `dp-clock-0.29.0.apk`. Если стоит сборка с debug.keystore — сначала удалите её (разные подписи). С 0.28.2 выпуск подписан ключом разработчика.

Исходный код — в этом репозитории.
