DP Clock 0.29.1 — исправление для прохождения модерации RuStore.

## Изменения

- Полностью удалена встроенная проверка обновлений через GitHub Releases, включая автоматическую проверку при запуске, ручную проверку, баннер, настройки и сохранение сведений о новых версиях.
- Удалены загрузка и установка APK из приложения, запрос разрешения «Установка неизвестных приложений», связанный `FileProvider` и `REQUEST_INSTALL_PACKAGES` в Android Manifest.
- Добавлена автоматическая проверка APK в CI и Release, предотвращающая повторное появление запрещённого разрешения.
- Номер версии: 0.29.1; `versionCode`: 38. Остальные функции приложения сохранены.

## Установка

Для RuStore используйте подписанный APK `dp-clock-0.29.1.apk` из этого релиза. Файл `*-debug.apk` предназначен только для отладки.

Последующие обновления приложения устанавливайте через RuStore либо вручную, а не через интерфейс DP Clock. При обновлении ранее установленной версии с тем же ключом подписи удалять приложение не требуется.
